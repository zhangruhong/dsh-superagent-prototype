# Web 卡片设计复刻方案

## 目标

在当前仓库中新增一个独立、可直接打开的 HTML/CSS/JS 页面，复刻参考图中的“设计鉴赏-Web卡片设计 1”工具入口页。页面需要保持参考图的深色背景、荧光标题、两组卡片网格、柔和 3D 插画和中文层级，同时提供可验证的卡片交互。

## 范围

交付内容位于独立的 `design-recreation/` 目录，不修改现有 `src/` 客户端业务逻辑。

包含：

- `index.html`：页面语义结构、卡片内容和可访问标签。
- `styles.css`：颜色、排版、网格、渐变、3D 插画容器、响应式和动效。
- `app.js`：卡片选中状态、跳转占位路径、键盘交互和移动端横向滚动增强。
- `assets/*.svg`：每个卡片的独立插画或 icon，页面通过文件引用使用。
- `placeholder.html`：跳转后的轻量占位页，显示所选工具名称和返回入口。

不包含真实 PDF/视频处理能力、账号体系、后端接口或第三方字体依赖。

## 页面结构

页面由 `main.page-shell` 包裹，分成三个区域：

1. `header.hero`：标题“设计鉴赏-Web卡片设计 1”，中文使用白色，英文和编号使用荧光黄绿色；副标题或辅助说明保持低对比度。
2. `section.feature-grid`：2×2 大卡片，依次为 PDF 转 Word、PDF 合并、视频转 MP4、PDF 转 PPT。大卡片保留标签、标题、说明和右侧插画。
3. `section.utility-grid`：三张窄卡片，依次为 PPT 创作、实时记录、阅读助手。每张保留独立 icon、说明和胶囊按钮。

卡片使用 `<article>` 与可聚焦按钮组合，保证点击区域明确。插画作为独立 `<img>` 引用，使用 `alt` 描述其用途。

## 视觉规则

- 页面背景：近黑色蓝紫底，避免纯黑造成死板对比。
- 主文字：高亮白；辅助文字：带冷色调的浅灰；标题强调色：荧光黄绿。
- 卡片：16–24px 圆角、轻边框、柔和内阴影；大卡片使用淡紫、淡青、薄荷绿和淡蓝四种底色。
- 资产：使用 SVG 绘制半透明叠层纸张、文件、播放三角形、麦克风、上传和 AI/PPT 图形，统一圆角、柔光和紫蓝青渐变。
- 空间：使用 8px 基准间距，桌面端保持宽松留白，标题与卡片之间有清晰层级。
- 动效：使用 `cubic-bezier(0.16, 1, 0.3, 1)`；卡片 hover/focus 上浮 4px、描边增强、阴影加深；尊重 `prefers-reduced-motion`。

## 交互与状态

采用已确认的 B 方案：

- 点击卡片或按钮时，为当前卡片添加 `is-selected`，保留选中描边和短暂上浮状态。
- 同时跳转到 `placeholder.html?tool=<slug>`，占位页展示工具名称、简短说明和“返回工具总览”按钮。
- 键盘 Enter/Space 与鼠标点击执行同一逻辑；焦点状态不能依赖 hover。
- 无效或缺少 `tool` 参数时，返回总览并显示默认说明。

工具 slug 固定为：`pdf-word`、`pdf-merge`、`video-mp4`、`pdf-ppt`、`ppt-create`、`realtime-record`、`reading-assistant`。

## 响应式

- 宽屏（≥ 1024px）：大卡片 2×2，底部卡片 3 列。
- 中等宽度（720–1023px）：大卡片 2 列，底部卡片 2 列。
- 窄屏（< 720px）：内容单列，大卡片纵向排列；底部卡片使用横向滚动并保留 snap 对齐，避免页面过长。
- 所有文字和按钮保持可读尺寸，图片使用 `max-width: 100%` 防止溢出。

## 资产清单

页面需要独立生成并保存以下 SVG：

- `pdf-word.svg`
- `pdf-merge.svg`
- `video-mp4.svg`
- `pdf-ppt.svg`
- `ppt-create.svg`
- `realtime-record.svg`
- `reading-assistant.svg`

这些资产只负责图形表现，标题、说明和按钮文字保留在 HTML 中，避免图片内文字在响应式和无障碍场景下失真。

## 验证

实现后需要完成：

1. 直接打开 `design-recreation/index.html`，确认页面无需构建即可显示。
2. 在桌面宽度检查标题、2×2 卡片、底部三卡片的比例和留白。
3. 在窄屏检查单列/横向滚动布局、按钮可点击区域和无横向溢出。
4. 点击每一张卡片和按钮，确认 `is-selected` 状态出现并跳转到对应 slug 的占位页。
5. 使用键盘 Tab、Enter、Space 完成交互，确认焦点可见。
6. 在 `prefers-reduced-motion: reduce` 下确认动画被压缩或关闭。

## 约束与取舍

- 参考图中的复杂插画使用独立 SVG 资产重绘，保证可离线打开、可缩放且不依赖外部图片 URL。
- 页面保持静态交付，不引入 React、打包器或第三方 UI 库。
- 原仓库是 TypeScript 包，新的静态目录不参与现有 `pnpm check`，但会单独进行浏览器手动验证。
